# 🏎️ Gabriel App - Gamificación de Rutinas Infantiles (Cars Theme)

[![Kotlin](https://img.shields.io/badge/Kotlin-7F52FF?style=flat&logo=kotlin&logoColor=white)](https://kotlinlang.org/)
[![Android](https://img.shields.io/badge/Android-3DDC84?style=flat&logo=android&logoColor=white)](https://developer.android.com/)
[![Status](https://img.shields.io/badge/Status-In_Development-orange)](#)

Aplicación móvil nativa para Android enfocada en la gamificación de tareas y rutinas diarias infantiles (lavarse los dientes, recoger juguetes, hacer los deberes). Diseñada con una ambientación visual basada en el universo de *Cars* (Pixar), utiliza animaciones e interacciones dinámicas para convertir el cumplimiento de hábitos en una experiencia lúdica.

---

### 🚀 Características Principales

- 🏁 **Gamificación de Hábitos:** Transformación de tareas cotidianas en objetivos dinámicos y divertidos.
- 🎬 **Interfaz Animada e Interactiva:** Uso intensivo de animaciones visuales para mantener el interés visual del usuario.
- 🕹️ **Botones de Acción Intuitivos:** Controles simplificados y adaptados para facilitar la navegación a un público infantil.
- 🎨 **Diseño Temático Adaptado:** Ambientación gráfica y estética personalizada inspirada en el universo del motor y la animación.

---

### 🛠️ Tecnologías y Herramientas

- **Lenguaje:** Kotlin
- **Plataforma:** Android SDK
- **UI & Animaciones:** Layouts interactivos, View Animations / Property Animations / Lottie
- **IDE:** Android Studio

---

### 🚧 Estado del Proyecto

El proyecto se encuentra actualmente en **fase de desarrollo (W.I.P.)**, ajustando el flujo de animaciones, la lógica de recompensa de tareas y la optimización de la interfaz.
